# NexusFlow — Front-End Project Management & Analytics App

## Included Files
- `index.html`: Complete, self-contained front-end application built with semantic HTML5, modern CSS3 (CSS Variables, Grid, Flexbox, Dark/Light Theme), and Vanilla JavaScript (ES6+ with `localStorage` persistence, Drag-and-Drop Kanban, SVG Charts, and CSV Export).

## How to Run
1. Extract the ZIP archive.
2. Open `index.html` directly in any modern web browser (Chrome, Edge, Firefox, Safari) or run via VS Code Live Server.
